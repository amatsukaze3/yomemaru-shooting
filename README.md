# よめ丸シューティング

おちてくる ひらがなカードを 声に出して よんで GET する、ひらがなの 音読ゲームです。
カードの絵の ことば（あり、かめ …）の 文字を ぜんぶ あつめると スタンプが もらえます。46こ あつめると コンプリート。

- ふつう モード … ゆっくり はじまって だんだん はやくなる
- はやい モード … まんなかの はやさから ぐんぐん はやくなる
- とちゅうセーブ・つづきから、スタンプずかん、ゴールまでの みちのり

公開ページ：https://amatsukaze3.github.io/yomemaru-shooting/

「ひらがなよめ丸」（https://amatsukaze3.github.io/hiragana-yomemaru/）の カード・音声判定・音声を つかった 単体版です。
このリポジトリの `index.html` は できあがった 1ファイルだけです。ソースは hiragana-yomemaru の `source/src/shooting/` にあります
（`npm run build:single:shoot` → `dist-single-shoot/shooting.html` を この `index.html` に コピー）。
